# 井 · El pozo

> 一個安靜的網頁小遊戲：進到井裡，計算你待了多久，沒有關卡、沒有輸贏

- **網址：** https://wangchiapin.github.io/unomismo/
- **Firebase 專案：** memorma-24dab（與 `Memorama`、`pop-colores-numeros`、`Ordena-el-Armario` 共用）
- **登入方式：** 匿名登入
- **狀態：** 使用中

## 玩法
- 開場文字會一個字一個字打出來，按「進入」就掉進井裡。
- 畫面上方顯示「你已經進入井裡 X天X小時X分X秒」，關掉網頁再回來，時間還是接著算。
- 每 10 分鐘換一句話（60 句，一句偏沉重、一句偏溫柔，輪流出現）；待超過 24 小時，改成溫和提醒（喝水、吃東西、出去走走）。
- 井裡的小孩姿勢會隨機更換（20 秒～3 分鐘不等）；偶爾出現「有光照下來」的畫面，台詞固定是「你要上來了嗎？」。
- 按 **Y**（或鍵盤 Y）離開：會顯示你待了多久，計時歸零，可再按「繼續回到井裡」。
- 按 **N**（或鍵盤 N）留下：說一句「那就再待一會兒吧。」

## 環境聲
- 預設關閉，按「聲音：關」開啟。
- 用 Web Audio 即時產生：遠處不規律的水滴（8～48 秒一次，帶回音）加上很輕的低沉風聲，不需要音檔。
- 分頁在背景時自動暫停，省電。

## 看看誰也在井裡
- 設定好 Firebase 後，會出現「看看誰也在井裡…」，顯示目前也在井裡的人數與方塊（最多 30 個，其餘用文字說明；方塊只是代表，不顯示任何個人資訊）。
- 匿名登入，不問名字、不記 IP；Firestore 集合 `well_visitors`，每人一筆，文件 ID 為匿名 uid，欄位：`enteredAt`、`lastSeen`。
- 進井、回訪、以及開著不關每 7 天會更新一次 `lastSeen`；按 Y 離開時刪除自己那一筆。
- 超過 30 天沒出現，就不再計入。
- 沒有設定 Firebase 時所有雲端功能關閉，遊戲照常運作；雲端出錯也不會影響遊戲。
- 預覽：網址後面加 `?demo=47` 可不連 Firebase，用假人數看畫面。

## 資料與隱私
- 進井時間存在玩家自己的瀏覽器（`localStorage` 的 `well.enter`）；無法使用時改記在記憶體。
- 雲端只存「是否還在井裡」與時間，沒有任何文字或個人資料。

## 技術
- 單一檔案 `index.html`（無需建置），畫面為 SVG／CSS，Firebase SDK 由 gstatic 載入。
- 部署：GitHub Pages。

- `index.html`：整個遊戲（單一檔案）。
- `og.jpg`：分享連結預覽的縮圖（1200x630）。

## 分享連結預覽（2026-10-28）
把網址貼到 LINE、WhatsApp 時，會顯示遊戲名稱「井 · El pozo」和縮圖 `og.jpg`；名稱與說明文字寫在 `index.html` `<head>` 的 `og:title`、`og:description`。
